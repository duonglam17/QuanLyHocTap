## 3. Tổng kết Phân tích & Hạng mục Thiếu

### 3.1. Số liệu Thống kê:
- **Tổng số Scenarios Gherkin:** **23 mục**.
- **Số mục đã có Unit Test & Frontend Test đầy đủ:** **23/23 mục** (100% logic nghiệp vụ được kiểm tra ở tầng cô lập).
- **Số mục Thiếu Integration Test với MySQL thật:** **23 mục** (Hiện tại `backend/tests/m1` dùng mock harness in-memory, chưa có file test tích hợp trực tiếp với cơ sở dữ liệu MySQL thật như `assessmentUsage.db.test.js` của M2).
- **Số mục Thiếu E2E Test (Playwright):** **6 User Stories** cốt lõi của hành trình Giảng dạy (US-03, US-04, US-05, US-06, US-17, US-18) chưa có tệp `e2e/specs/e1-giang-day.spec.js`.

### 3.2. Rà soát Quy tắc nghiệp vụ (BR) & Tình huống biên (EC):
1. **BR-09 (Bảo mật điểm số):**
   - *Trạng thái:* **Không áp dụng trực tiếp cho Module M1** (Kèm lý do: Điểm số bài tập thuộc quản lý của Module M2, điểm thi trắc nghiệm thuộc Module M3. Module M1 không lưu trữ hoặc xử lý bảng điểm, chỉ phối hợp qua Ports `assessmentUsage` và `quizUsage` khi kiểm tra điều kiện hủy ghi danh hoặc lưu trữ khóa học).
2. **EC-20 (Tên tệp tiếng Việt / ký tự đặc biệt):**
   - Đã có test kiểm tra việc chuyển tên lưu trữ sang UUID và giữ `original_filename` trong response `Content-Disposition`. Cần bổ sung test tích hợp DB thật ở bước T2.
3. **EC-22 (Chống Brute-force Enrollment Key):**
   - Đã có test rate limit 429 trên route `POST /api/courses/enroll` trong `backend/tests/m1/course.test.js` và trên UI `frontend/src/modules/m1/pages/CoursesPage.test.jsx`. Cần bổ sung test tích hợp DB thật ở bước T2.
4. **EC-01 (IDOR bảo vệ tài liệu và lịch học):**
   - Đã có test ở tầng Service và Router kiểm tra trả về 403 Forbidden khi sinh viên chưa ghi danh cố tình truy cập.
5. **EC-23 & EC-24 (Xung đột lịch học, Đổi lịch, Hủy lịch):**
   - Đã có test kiểm tra mã 409 `SCHEDULE_CONFLICT`, trạng thái `RESCHEDULED`, `CANCELLED` và gửi thông báo qua Port `notifications`. Cần bổ sung test tích hợp khóa dòng (Row locking `SELECT ... FOR UPDATE`) trên MySQL thật ở bước T2.
