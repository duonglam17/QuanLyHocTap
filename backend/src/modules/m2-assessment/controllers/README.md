# M2 - Controllers (Tầng Điều hướng & Tiếp nhận Request)

Chứa các Controller phụ trách nhận request cho phân hệ Bài tập và Bảng điểm:

- `assignmentController.js`: Tạo bài tập, lấy danh sách bài tập của khóa học, đóng/mở bài tập (US-07).
- `submissionController.js`: Sinh viên nộp bài tập, nộp lại bài, tải bài nộp cá nhân (US-08).
- `gradeController.js`: Giảng viên chấm điểm bài tự luận, nhập lời nhận xét (US-09).
- `gradebookController.js`:
  - Sinh viên xem bảng điểm cá nhân (US-13).
  - Giảng viên xem bảng điểm tổng hợp lớp phân trang (US-14).
  - Xuất bảng điểm ra file CSV an toàn (US-14, BR-16).
