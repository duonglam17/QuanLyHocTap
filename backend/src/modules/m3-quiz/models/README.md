# M3 - Models (Tầng Thực thể & Cấu trúc Dữ liệu)

Chứa các cấu trúc dữ liệu và ánh xạ thực thể thuộc M3, khớp với schema CSDL:

- `Quiz`, `Question`, `Option`, `Attempt`, `AttemptAnswer`.
- `Announcement`, `Discussion`, `Notification`.

Models chỉ mô tả dữ liệu; không chứa logic nghiệp vụ hoặc truy vấn CSDL.
